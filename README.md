# ساعة ومنبّه Android

تطبيق Android أصلي مبني باستخدام Kotlin وJetpack Compose وMaterial 3.

تتضمن النسخة الحالية ساعة تناظرية ورقمية محلية مع التاريخ الميلادي، وإدارة
منبّهات مع التعديل والتشغيل والإيقاف. يمكن ضبط صوت المنبّه أو جعله صامتًا،
وتسمية كل منبّه اختياريًا؛ تظهر التسمية في القائمة وإشعار الرنين. تعرض الساعة
التناظرية أرقام الساعات الاثنتي عشرة وتدريجات دقيقة لكل دقيقة، مع علامات أوضح
لكل خمس دقائق. تستخدم التنبيهات الصوتية نغمة قصيرة كنقطة
مورس، وتدعم واجهة الرنين الغفوة. يمكن إضافة رابط ويب وزر بتسمية مستقلة لكل
منبّه؛ يقبل أي رابط ويب HTTP أو HTTPS بما في ذلك روابط YouTube، ويفتحه في
التطبيق المناسب.
ومن إعدادات المنبّهات يمكن تفعيل تجاوز وضع عدم الإزعاج للمنبّهات الصوتية بعد
منح إذن سياسة الإشعارات من Android؛ ويظل صوت المنبّه ومستوى صوته خاضعين للنظام.
تتضمن نافذة الرنين زرًا لفتح رابط المنبّه ولونًا اختياريًا له، وزرًا لكتم أو
إعادة صوت الرنين. تستخدم إشعارات المنبّهات المفعّل صوتها وتذكيرات المواقيت
والمناسبات نغمة مورس القصيرة. يتيح قسم المواقيت مفتاحًا مستقلًا لكل صلاة،
إضافة إلى الجمعة ورمضان وعرفة والعيدين وبدايات الفصول الأربعة؛ وتُجدول التنبيهات
عند حلول الموعد وفق الموقع وإعدادات الحساب المختارة.
تعرض الساعة أيضًا التاريخ الهجري وفق تقويم أم القرى.
تظهر واجهة الرنين على شاشة القفل، ويُعرض إشعار عالي الأولوية فوق التطبيقات؛
ويعتمد فتح الواجهة كاملة الشاشة على إعدادات Android وحالة الجهاز. تبقى واجهة
الرنين مفتوحة حتى اختيار الإيقاف أو الغفوة. يدعم
التكرار كل دقيقة أو ساعة أو يوم أو أسبوع أو شهر أو سنة، أو مرة واحدة؛ ويتبع
التكرار الشهري يوم التاريخ المحدد والسنوي الشهر واليوم. يتطلب العرض الكامل
والتوقيت الدقيق أذونات النظام المناسبة، وقد تظل بعض القيود الخاصة بـ Android
ووضع توفير الطاقة سارية.
تعرض مواقيت الصلوات الخمس، منتصف الليل الشرعي والثلث الأخير، والمناسبات
الهجرية والفصول مع عدّادات تنازلية. يمكن استخدام GPS أو اختيار مدينة، وتغيير
طريقة الحساب والعصر وتصحيح دقائق كل صلاة. يعتمد GPS على المنطقة الزمنية
المضبوطة في الجهاز؛ المدن تستخدم مناطقها الزمنية المعروفة.
تتضمن الواجهة ساعة عالمية قابلة للتخصيص لمدن ومناطق زمنية متعددة، تعرض الوقت
والتاريخ وفارق UTC والفارق عن الجهاز. تُحسب فروق التوقيت آنيًا، بما فيها
التوقيت الصيفي، دون تغيير المنطقة الزمنية لمواقيت الصلاة والأحداث والعدّادات؛
تبقى هذه مرتبطة بالموقع المحدد للمواقيت، وكلها تستخدم اللحظة الزمنية نفسها.
تستخدم أيقونة تشغيل حديثة عالية التباين رمز اللانهاية مع أجراس التنبيه، وتدعم
الأيقونات التكيفية ودرجات كثافة Android من mdpi إلى xxxhdpi.
تنظم الواجهة الأقسام عبر شريط تنقل سفلي: الساعة، المواقيت، الساعة العالمية،
والمنبّهات والإعدادات؛ تبقى لحظة الساعة والعدّادات مشتركة عند التنقل، وتحفظ
حالة التبويب والتمرير. من إعدادات المنبّهات يمكن فتح إعداد Android الخاص
بإذن الظهور فوق التطبيقات وفحص حالته بعد العودة. عند تفعيل الساعة العائمة،
يفتح التطبيق إعداد الإذن الخاص عند الحاجة ثم يعرض ساعة قابلة للسحب فوق
التطبيقات عبر foreground service وإشعار دائم مع زر للإيقاف. منح الإذن أو
سحبه بيد المستخدم عبر إعدادات النظام؛ وقد تمنع سياسات Android أو قيود
الشركات المصنّعة العرض فوق بعض النوافذ الحساسة، ولا يمكن تجاوز ذلك.
سجل التنفيذ والقيود والخطوات التالية في
[سجل التقدم الهندسي](docs/engineering-progress.md).

## البناء والاختبارات

يتطلب JDK 17 وAndroid SDK 36. شغّل الاختبارات وابنِ نسخة Debug باستخدام:

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

ينتج ملف التثبيت في `app/build/outputs/apk/debug/app-debug.apk`.

المشروع الحالي تطبيق Android أصلي؛ لا يحتوي حتى الآن على تطبيق Flutter أو
نسخة iOS.

يعمل سير GitHub Actions عند تحديث الفرع `main`، وطلبات السحب، أو تشغيله يدويًا
من تبويب Actions. يرفع نسخة Debug باسم `Android-Clock-Debug-APK` ولا ينشر
إصدارًا إنتاجيًا.
