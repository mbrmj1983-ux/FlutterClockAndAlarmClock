# ساعة ومنبّه Android

تطبيق Android أصلي مبني باستخدام Kotlin وJetpack Compose وMaterial 3.

تتضمن النسخة الحالية ساعة تناظرية ورقمية محلية مع التاريخ الميلادي، وإدارة
منبّهات مع التعديل والتشغيل والإيقاف والتكرار الأسبوعي أو اختيار موعد من
التقويم. يدعم كل منبّه التنبيه البصري والصوتي المستقل، بما في ذلك وضع صامت
وواجهة تذكير مع الغفوة. تعرض الساعة أيضًا التاريخ الهجري وفق تقويم أم القرى.
تعرض مواقيت الصلوات الخمس، منتصف الليل الشرعي والثلث الأخير، والمناسبات
الهجرية والفصول مع عدّادات تنازلية. يمكن استخدام GPS أو اختيار مدينة، وتغيير
طريقة الحساب والعصر وتصحيح دقائق كل صلاة. يعتمد GPS على المنطقة الزمنية
المضبوطة في الجهاز؛ المدن تستخدم مناطقها الزمنية المعروفة. يظل ظهور التنبيه
على شاشة القفل وملء الشاشة خاضعًا لإصدار Android وصلاحيات المستخدم وإعداداته.
تتضمن الواجهة ساعة عالمية قابلة للتخصيص لمدن ومناطق زمنية متعددة، تعرض الوقت
والتاريخ وفارق UTC والفارق عن الجهاز. تُحسب فروق التوقيت آنيًا، بما فيها
التوقيت الصيفي، دون تغيير المنطقة الزمنية لمواقيت الصلاة والأحداث والعدّادات؛
تبقى هذه مرتبطة بالموقع المحدد للمواقيت، وكلها تستخدم اللحظة الزمنية نفسها.
سجل التنفيذ والقيود والخطوات التالية في
[سجل التقدم الهندسي](docs/engineering-progress.md).

## البناء والاختبارات

يتطلب JDK 17 وAndroid SDK 36. شغّل الاختبارات وابنِ نسخة Debug باستخدام:

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

ينتج ملف التثبيت في `app/build/outputs/apk/debug/app-debug.apk`.

المشروع الحالي تطبيق Android أصلي؛ لا يحتوي حتى الآن على تطبيق Flutter أو
نسخة iOS.

يعمل سير GitHub Actions عند تحديث الفرع `main`، وطلبات السحب، أو تشغيله يدويًا
من تبويب Actions. يرفع نسخة Debug باسم `Android-Clock-Debug-APK` ولا ينشر
إصدارًا إنتاجيًا.
